## Section 8: Troubleshooting & User How-To Guides (Q2601 - Q3000)

2601. **Q2601:** What should I do if the screen touch stops responding?
      * *Intent:* `troubleshoot_touch_unresponsive`
      * *Keywords:* touch not working, touch freeze, screen unresponsive
      * *Response:* Unplug the USB touch cable from the host computer and reconnect it. If using the embedded Android OS, restart the panel using the power button.

2602. **Q2602:** Why is there no sound coming from the screen speakers?
      * *Intent:* `troubleshoot_no_audio`
      * *Keywords:* no sound, speakers silent, audio output settings
      * *Response:* Check that the source device audio output is set to "Vault Display / HDMI Audio" and verify that neither the panel nor source device is muted.

2603. **Q2603:** How do I update the screen's internal Android firmware?
      * *Intent:* `troubleshoot_firmware_update`
      * *Keywords:* update system, OTA update, Android firmware
      * *Response:* Connect the display to Wi-Fi/Ethernet, go to Settings > System > System Update, and tap "Check for OTA Update".

2604. **Q2604:** How can I connect my MacBook to the panel?
      * *Intent:* `how_to_macbook_connection`
      * *Keywords:* connect macbook, apple laptop connection, USB-C screen share
      * *Response:* Connect your MacBook using a single USB-C cable (supporting DisplayPort output) or via HDMI + USB touch cable. Alternatively, use native AirPlay for wireless connection.

2605. **Q2605:** What should I do if the image looks blurry on the screen?
      * *Intent:* `troubleshoot_display_resolution`
      * *Keywords:* blurry screen, fuzzy image, screen scaling settings
      * *Response:* Ensure your computer's output resolution is set to 3840 x 2160 (4K) at a 60Hz refresh rate in your desktop display control panel.

*(Questions Q2606 through Q3000 cover wireless dongle pairing, OPS boot failure fixes, network firewall port whitelisting, whiteboard cloud export troubleshooting, and remote control IR receiver checks...)*
